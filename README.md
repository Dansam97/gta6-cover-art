Vice Frame — Neon Cover Studio is an offline web app that turns your own photos and a caption into GTA-style multi-panel cover art with a Vice City neon-sunset colour grade. Drop in one photo or several, arrange them across four panel layouts (Classic 6, Hero + Trio, Neon Strips, Quad Grid), drag and zoom each panel, edit the big stacked title, subtitle and badge, pick from four colour grades, and export a share-ready PNG at 1080x1080, 1080x1350 or 1920x1080. Everything runs locally in the browser from static files — photos are never uploaded — and empty panels are filled with original vector scenery, so a striking poster is only a few clicks away.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in a desktop browser, add your photos, then Export PNG
# to build the hand-in dossier instead: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
